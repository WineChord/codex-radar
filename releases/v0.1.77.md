# v0.1.77

## 更新内容

- 网络暂时不可用时，菜单栏继续显示上次额度并标记“缓存”，菜单显示上次成功更新时间。
- 额度保存到本机私有文件，重启后仍可查看；恢复连接后自动刷新，成功后恢复实时显示。
- 缓存期间暂停用量建议；简化网络错误提示，并在缓存无法读写时明确提醒。

## Changes

- Keep the last quota visible with a Saved label during outages and show its last successful update time.
- Preserve quota in a private local file across restarts; refresh automatically and restore live readings when the connection recovers.
- Pause usage guidance while quota is cached, simplify network errors, and report cache read or write failures.
